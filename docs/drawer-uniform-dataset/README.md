## 时序与数据

输出i、i+87对应同一源i，u分别为i/174和(i+87)/174，相差0.5；174点在[0,1)均匀分布。
A拿起并举到原持物最高区域，B开屉，C等A/B完成后放入；关屉等左臂退出。
保留最高区域2mm容差、0.5秒减速和0.3秒启动、同源动作及视频时钟。
抽屉宽0.178m、深0.20m来自用户实测，高0.07m仍为未实测估计；不检查持物球，
保留现有机械臂/夹爪对抽屉的检查，二维投影重叠不作为规划拒绝。

顶视图复用仓库已有原始深度合成路径，深度和RGB使用相同裁剪偏移、配准及源时钟。
左右腕视频分别按各自源时钟导出。Action/State分别按左右源时钟插值，写回源存储精度。

## 人工处理及失败证据

人工处理3个源，未超过最多5源的额度。[完整账本](manual-interventions.json)。

1. 源60沿用前序证据修正approach_start：323→196，避免漏掉真正接近和闭合。
2. 源35原close_start=343错误地截在右手夹爪调整；原视频到535仍开屉，之后进入
   最后关屉动作。改为保守的最终关屉接近起点535，保留全部记录动作；这也允许
   合成器使用放入后实际清晰的背景，消除原输出柜体破碎像素。
3. 源61右臂遮罩把抽屉底板及后来放入的立方体错当成右臂，导致第二变体等待时
   提前出现抽屉内物体。依据同源配准图像，清除源帧[204,498)右臂遮罩的底板多边形：
   (376,199)、(474,174)、(554,250)、(428,298)，坐标对应640×362分析图。
   左臂、物体遮罩、RGB/深度、Action/State和时序定义不变；保留多边形外的右臂遮罩。

两源已真实重新plan/render，三个相机和数值再次验证。没有复制其他源、修改视频hash、
伪造动作、降低最高点或取消机械臂检查。所有原失败输出保存于运行根的
`rejected-initial/`；最初批次状态只是数值通过，不能替代最终视觉记录。

扩大遮罩、共性背景/所有权代码等诊断方案未完全解决问题，未合入本成品代码，
保留在各自probe/runtime目录。最终仍使用a29cc6b和明确记录的逐源标注。
