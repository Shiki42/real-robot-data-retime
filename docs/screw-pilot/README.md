# 插螺丝：靠近就位、平滑等待、协同插入

源数据为 `Shiki42/piperx-screw-0910-25ep-raw`，固定 revision
`824b6382ef4858213e6ea42ea61104110d911448`。取 episode 1，生成三条完整五轮样例。

拾取段包括向中央靠近：左臂拿到套筒后到中央就位；右臂拿到螺丝后，
在接触前停靠。后四轮左臂的「收纳上一件＋拿下一个套筒＋靠近就位」保持连续。
提前完成的一臂在就位姿态等待另一臂，双方准备好后平滑完成最后一段接近，
同时进入原始协同插入。

## 源时间与平滑

每臂复用 `lift_clock` 的单调源时间曲线：0.5 秒减速、0.3 秒启动。
两臂独立变速；一臂停靠时，另一臂保持自身的原轨迹进度。
准备段的相对起始时间复用 `stage_delays` 均匀采样。
最后接近段错开两臂的启动，使它们以原速同时接入原始协同区间。

`compress_static_spans` 只压缩减速区间之前、state 与 action 全区间变化
均不超过 0.3° / 0.5 mm 的静止帧。减速、启动与实际插入均受保护。
其他运动不跳过；源时间大于一帧的跳跃必须再次通过完整静止范围检查。

每条样例每臂有 110 个非整数源时间帧。`sample_rows` 同步插值 action/state；
主视角的整臂及携带物前景由 `FlowFrames` 插帧，左右腕视频由既有
`remap_video` / `_SequentialVideoReader.sample` 使用相同源时间插帧。
等待期间动作、状态与各自腕视频保持对应边界帧。

五次实际插入仍逐帧使用原始同步整帧，末次收纳保持原样。

## 视频合成

主视角为 `observation.images.right_environment_1`。
整臂分割复用 `SamVideo`；背景曝光配准、真实像素恢复、轨迹导出和像素校验
复用现有实现。套筒区与收纳盒跟随左时钟，螺丝区跟随右时钟；整臂可跨越空间分界。

另行跟踪拾取后的螺丝头与露出的螺杆，并与右臂掩码合并。
这些携带物也随右臂插帧，并从错误源时间的背景中移除，避免收纳盒边缘残影。
物体掩码仅在对应拾取之后生效。第五轮右臂撤回仍保留独立的跟踪播种。
RGB 投影重叠沿用原有右臂前景顺序，调度使用用户给定的独立工作区假设。

## 验证

- 全部 action/state 精确匹配同一组连续源时间的插值结果。
- 主视角与双腕视频的所有帧数、PTS 与输出时间轴一致。
- 双腕视频逐帧校验，覆盖所有等待帧和插帧；每条另抽查 30 个同步保护段主视角帧。
- 每次停靠的源时间速度逐渐减小，等待中不漂移，启动后逐渐恢复；无段内暂停或新加双臂同时等待。
- 实际插入与末次收纳逐帧保持原始同步；最后接近的加速在实际插入之前完成。
- 视觉检查覆盖五轮双方先行的就位、等待、启动和插入；螺丝头残影有修正前后对照。

详细数值及画面抽查帧号见 `validation.json` 和 `visual-review.json`。
