## 关键判断及尚未授权的范围

二维投影交集不等于物理碰撞；现有 uniform 路线把它作为无法可靠合成的拒绝
条件。仓库已有 `AlignedDepth` 和深度合成路径，但当前 uniform 没有使用它。
例如源7共有36个开屉帧与峰值mask交叠，最大30像素；这些帧的双臂网格端点
检查均通过，有效深度的最小差为58mm。不过524个重叠像素帧中有44个缺深度。
这不能证明整个连续轨迹可用，也不能将缺失深度交给默认前后顺序后宣称通过。

其他代表源还出现原始深度与默认网格模型的冲突。没有修改0.49m默认基座间距、
24×20×7cm抽屉代理或3.5cm物体球半径，也没有重新标定的证据。不能把这些拒绝
判作实际物理不可能。全扫掠候选前置约束与后续瞬时抽屉检查也值得进一步核查。

已向用户询问是否允许研究“有深度和几何证据的新遮挡合成”，还是所有重叠继续
只允许同源帧、两臂同时前进1的原速回放。检查点保存时尚未收到答复，未据预选项
实施新遮挡路线。2mm峰值容差、A/B定义、两相位差0.5、平滑时长均未修改。
