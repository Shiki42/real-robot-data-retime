逐源读取真实顶视视频，以静止背景特征估计相机平移，再测量柜体红色轮廓和上层
蓝色固定把手相对背景的位置。剔除机器人贴近/遮挡把手的观测，结合柜体图像配准
和带初始轮廓叠加的原视频帧复核；正常下层抽屉开合不作为柜体移动。

保守筛选阈值为640像素宽分析画面中，无遮挡固定把手相对背景位移的90百分位
达到4像素，并复核柜体轮廓。这包括明显滑移/转动及持续晃动，也能发现后来复位
的情况，例如源2。源35的位移约28像素，不只是原先关屉边界过早的问题。

这是一项针对固定背景/几何假设的风险筛选，不是力学测量；并不表示28源此前均
实际生成失败，也不声称保留源物理上绝对静止。1–3像素级曝光、追踪变化没有
直接当作推动而剔除。原始脚本、指标、独立背景匹配和配准结果均保存，可复核。

## 新时序

- 均匀网格按59个保留源重新生成：u=(保留源序号+variant×59)/118。
  输出0–58是变体0，59–117是变体1；每源位置相差0.5，原始源编号保留在receipt。
- 删除旧原速成对回放策略中“把举高后的右臂源帧全部加回”的逻辑，让已有静止段
  压缩真正生效；仅压缩state/action共同满足已有静止范围阈值的片段。
- 释放物体后，检测左TCP持续向上或向外回撤的首个运动区间：0.1秒窗口，累计至少
  2mm，首步必须沿退出方向。无较早回撤证据时，已完全退出本身仍是有效节点。
- 在旧完全退出节点之前启动关屉的候选，额外连续检查state/action两臂网格和
  左臂相对抽屉完整扫掠体积；不够间隙则由调度器继续等待。
- 保留原始实际运动、松爪和调整；不跳过运动姿态，不重构关屉轨迹。A/B/C定义、
  最高区域2mm条件及0.5/0.3秒等待平滑保持不变。

本批次允许节点到关屉段启动的中位间隔约0.033秒，34条输出早于旧完全退出节点
启动关屉。[逐条时序记录](timing-summary.json)。这里的关屉段启动不等于抽屉已经
完全关闭；真实关屉动作和右手调整仍需其原始时长。
